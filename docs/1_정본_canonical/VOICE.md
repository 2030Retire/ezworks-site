## 0. 한 줄 원칙

> **약속하지 말고 이름을 붙인다. 말 걸지 말고 구조를 서술한다.**

"~해드립니다 / ~합니다"는 화자 중심 약속문이라, 내용이 좋아도 **벤더 목소리**가 된다.
고급스러움은 형용사를 더해서 생기지 않는다. **동사와 화자를 지우면** 생긴다.

---

## 1. 제목 — 명사구로 끝낸다

| ⛔ | ✅ |
|---|---|
| 업무를 먼저 정리하고, 그다음에 자동화**합니다** | 일하는 구조를 바꾸는 **방식** |
| 우리가 프로세스를 정리해**드립니다** | 정리는 먼저, 자동화는 **그다음** |

**CPAFlow 실례**
- `사람을 더 뽑지 않고, 고객을 늘리는 방식` ← `방식`으로 종결
- `채용 없이 고객 수를 늘리는 구조` ← `구조`로 종결

종결 명사 후보: **방식 · 구조 · 순서 · 자리 · 일 · 것 · 차이**

---

## 2. 섹션 제목 — 대구(對句) + 동사 생략 ⭐ 서명 특징

**CPAFlow 실례**
```
입력은 시스템이, 판단은 사람이
인건비는 유지, 처리 고객 수는 확장
사람이 바뀌어도, 운영은 그대로
쓸수록 정확해지는 운영 시스템
```

`A는 X, B는 Y` 골격. **동사를 아예 쓰지 않는다.**
EZWorks 적용 예: `규칙은 시스템이, 판단은 사람이` · `도구는 그대로, 흐름만 바꾼다`

---

## 3. 판단·정의 문장 — 체언으로 끊는다

`~입니다`로 닫지 않고 명사 + 마침표로 끊는다. 단정이 아니라 **정의**로 읽힌다.

**CPAFlow 실례**
```
북키퍼 1명의 처리 한계는 업무량이 아니라 구조의 문제.
처리 용량의 병목을 인력에서 시스템으로 이동하는 것.
북키퍼 이직은 회계펌 운영의 가장 큰 리스크 중 하나.
```

⚠️ **본문 설명 문단은 `~합니다` 허용.** 제목과 논지 문장만 체언 종결.
전부 체언으로 끝내면 읽기 힘들어진다.

---

## 4. 섹션마다 영문 eyebrow

**고급스러움의 절반이 여기서 나온다.** 판매 섹션이 아니라 **분석 문서의 챕터**로 읽히게 만든다.

**CPAFlow 실례**: `Operational Challenges` · `How It Works` · `Business Impact` ·
`Learning System` · `Operational Stability` · `Positioning` · `Before & After`

EZWorks 후보: `Readiness` · `How It Works` · `What We Build` · `Engagement` ·
`Delivery Speed` · `What We Turn Down` · `Positioning`

⚠️ 한국어면도 eyebrow는 **영문 유지.** 이게 톤을 만든다.

---

## 5. 주어를 지운다

"우리는 / 저희가 / 당신을 위해"를 쓰지 않는다. 주체는 **구조·시스템·프로세스**다.

| ⛔ | ✅ |
|---|---|
| 저희가 프로세스를 정리해 드립니다 | 프로세스가 문서로 남는다 |
| 우리는 한 번에 한 프로세스만 맡습니다 | 계약 단위는 프로세스 하나 |
| 당신의 업무를 자동화합니다 | 반복 입력이 시스템으로 넘어간다 |

---

## 6. 부정 대비로 재정의한다

**CPAFlow 실례**
> "문제는 일의 양이 아닙니다. 전문 인력이 반복 입력에 묶여 있는 **구조가 문제**입니다."

`X가 아니라 Y` 골격. 상대의 오해를 먼저 지우고 진짜 축을 세운다.
EZWorks: `실패하는 지점은 AI가 아니라 그 앞의 구조.`

## 7. ⛔ 절대 금지

| 금지 | 이유 |
|---|---|
| 의문형 제목 (`~는 무엇이 다른가`, `~일까?`) | 유튜브 썸네일 어법. 답을 미끼로 거는 구조 |
| `N가지 이유 / N가지 방법` | 콘텐츠 팜 어법 |
| 이분 대비 제목 (`A와 B의 차이`) | 리스티클 상투구 |
| 과장 부사 (`완전히`, `혁신적으로`, `놀랍게`, `획기적`) | 형용사가 일하면 내용이 약한 것 |
| 느낌표 | |
| `~해드립니다` · `~해 드리겠습니다` | 하청 어투 |
| 감탄·자화자찬 (`업계 최고`, `검증된`) | 사회적 증거 금지 규칙과도 충돌 |

## 8. 숫자 표기

CPAFlow는 숫자를 카드로 크게 노출하되 **라벨을 붙이고 느낌표를 쓰지 않았다.**
```
→ 0        반복 데이터 입력 목표치
1–2일      마감 처리 기간 (기존 3–4일)
99%+       데이터 정확도
```
- 목표치는 `목표치`라고 적는다 — 실적으로 위장하지 않는다
- 비교값을 괄호로 병기한다 (`기존 3–4일`)
- EZWorks에서는 `[SAMPLE]` 표기 규칙을 함께 지킨다 (`EVIDENCE_LEDGER` §3)

## 9. 적용 체크리스트 (문구 작성 후 자문)

1. H1이 동사로 끝나는가 → 명사구로 바꾼다
2. `우리 / 저희 / 당신` 이 있는가 → 지운다
3. 섹션 제목에 동사가 있는가 → 대구로 바꿔 동사를 뺀다
4. 영문 eyebrow가 모든 섹션에 있는가
5. 논지 문장이 `~입니다`로 끝나는가 → 체언 종결로
6. 형용사·부사가 의미를 지고 있는가 → 명사·동사로 옮긴다
7. §7 금지 목록에 걸리는 게 있는가

## 문장 종결 — 자리별 고정 (2026-08-22 확정)

같은 지적 3회 반복 후 규칙화. 「~합니다」가 금지어가 아니라, **모든 자리에 같은 종결을 쓰는 것**이 문제.

| 자리 | 종결 | 예 |
|---|---|---|
| 제목·소제목 | 명사구 | 병목의 위치 / 기능 추가가 아닌 층 제거 |
| 개요·정리·결과 항목 | 명사 종결 | 도크 중복 입력과 스테이지 탐색 제거 |
| 판단 기준 문장 | 점검형 + 필요 | 원인이 인력이나 설비인가. 먼저 살펴볼 필요가 있습니다 |
| 설명·서술 본문 | 「~습니다」 허용 | 서로 데이터를 주고받고 있었습니다 |
| 표·목록 | 명사 · 화살표 | 3명 이상 → 1명 |

### 영구 금지

- **「운영에 정착했습니다」류 자기 보증** — 한 사례에만 쓰면 나머지는 정착 안 한 것이 된다. 정착은 기본 전제. 「성공적으로」「안정적으로」「효과를 보고 있습니다」 동일.
- **내부 등급 용어 노출** — 「구조상 확정」「실측」「측정 필요」는 근거 관리용. 페이지에 나가면 변명으로 읽힌다. 측정 안 된 항목은 등급을 붙이지 말고 **뺀다**.
- **인원 감축 주장** — 실제로 사람을 줄이지 않았다. 「도크 처리에 3명 이상 → 슈퍼바이저 1명」처럼 *필요 인원*으로만 쓴다.
- **측정 조건이 성립하지 않는 지표** — 한가한 시즌엔 처리 건수·지연 비율에 변화가 없다. 「측정 필요」로 남기지 말고 지운다.
